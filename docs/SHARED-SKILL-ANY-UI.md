# Shared Skill/Any selection UI

The shared open-subject selector preserves the distinction between a source-open Skill domain and a closed canonical domain. Art/Any now presents suggested `Art/Dance`, `Art/Drawing`, `Art/Music`, `Art/Painting`, `Art/Poetry`, `Art/Sculpture`, `Art/Songwriting`, and `Art/Writing` specialties, plus `Other (specify)`. The suggestions are convenience options, not an exhaustive rules list.

Selecting a suggestion or entering a valid custom specialty resolves the existing typed Skill destination and retains its award provenance and XP. Empty, overlong, control-character, or slash-containing subjects remain invalid. Unresolved choices continue to block progression. Existing saved custom subjects, including `Art/Sculpture`, remain compatible through the unchanged character codec and import validation.

The same open-subject component is used for other supported source-open domains such as Career, Interest, Science, and Survival. Closed domains such as Technician, Security Systems, Driving, and Tracking remain dropdown-only. Context-bound Protocol and Streetwise choices retain their affiliation-derived restrictions. No additional open domains were introduced by this rollout.
