# Trait catalog audit - Alpha Slice 112

The authoritative inventory is the A Time of War Corrected Third Printing, printed pp. 106-128, with the applicable v4.0 Errata. The master list identifies 50 named Traits plus the neutral Phenotype entry. The catalog below promotes only concrete character Traits whose identity and TP levels can be represented by the existing ledger and legality engine.

## Governed Point Buy identities

The governed catalog increases from 6 to 32 entries. Promoted definitions preserve canonical IDs, signed XP, exact source TP levels, source pages, category, and existing opposed-Trait handling. Variable levels use only the source-defined increments: Poor Vision [-9..-2], Unlucky [-10..-2], Poor Hearing/Lost Limb [-5..-1], and the existing Reputation [-5..-1,+1..+5].

Promoted concrete character Traits: Animal Antipathy, Animal Empathy, Attractive, Combat Paralysis, Combat Sense, Fast Learner, Fit, G-Tolerance, Glass Jaw, Good Hearing, Good Vision, Gregarious, Gremlins, Illiterate, Impatient, Introvert, Lost Limb, Pain Resistance, Poison Resistance, Poor Hearing, Poor Vision, Sixth Sense, Slow Learner, Tech Empathy, Toughness, and Unlucky. Existing Ambidextrous, Patient, Unattractive, Reputation, Exceptional Attribute, and Phenotype identities remain stable.

## Explicitly not promoted

Alternate ID, Bloodmark, Citizenship/Trueborn, Compulsion, Connections, Custom Vehicle, Dark Secret, Dependents, Design Quirk, Enemy, Equipped, Extra Income, Handicap, Implant/Prosthetic, In For Life, Natural Aptitude, Property, Rank, Title/Bloodname, Vehicle Level, and Wealth require concrete identity/subject, affiliation, vehicle, equipment, GM, or other dependencies not safely represented by the current Point Buy input. They remain source-defined but unsupported here. Flexible and repeatable instances remain available only where an existing governed parameter model is present (currently Reputation and Exceptional Attribute).

The catalog does not automate gameplay effects. The record sheet preserves canonical identity, attained TP, signed XP, parameters, source page, and an explicit unsupported-effects status. This is a governed supported subset, not a claim that every source Trait is playable through every creation method.

## Verification and checkpoint

Automated coverage verifies exact TP ranges, source pages, category-derived negative-Trait accounting, opposed-Trait regression behavior, record-sheet provenance, and Slice 111 Skill/readiness/persistence regressions. Reference Fields remain 56, mechanical Fields 50, and equipment records/IDs remain 84. Release metadata is `0.1.0-alpha.112`.
