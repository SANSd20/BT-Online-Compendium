# G1h-D3 — Sian Commonality Citizenship Award

Sian Commonality is a supported Capellan sub-affiliation using the existing
Stage 0 affiliation transaction. Its source-backed award is `Citizenship +50
XP` (A Time of War — Corrected Third Printing, printed p. 64).

The award is represented by the canonical `trait.citizenship` identity with a
non-empty `subject` parameter and an active ledger record. The Sian transaction
retains the parent Capellan awards, records the Sian source provenance, and
does not grant Citizenship to Capellan Commonality or other Capellan paths.

The resulting record satisfies the existing Capellan Stage 2 Military School
and Stage 3 Citizenship gates. Parent-only selection remains unchanged, and
the existing persistence/provenance model remains authoritative. General
Citizenship purchasing remains deferred.
