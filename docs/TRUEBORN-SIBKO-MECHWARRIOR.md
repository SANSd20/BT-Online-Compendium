# Trueborn Sibko MechWarrior branch

Alpha Slice 142 adds an internal, source-backed Trueborn Sibko MechWarrior branch. It is available to the engine and persistence model for governed Clan-path testing; Clan character creation remains unavailable in the player-facing UI.

The branch requires Clan affiliation, Warrior caste, Trueborn identity, MechWarrior Phenotype, and Trueborn Crèche history. The source-defined 1,600 XP Sibko module records 16 years of chronology and grants BOD +40, DEX +60, RFL +50, WIL +20, CHA −30, Compulsion/Clan Honor −50, Rank +200, Career/Soldier +80, Interest/Clan Remembrance +50, and Negotiation +50.

The MechWarrior branch additionally grants Custom Vehicle +200, Vehicle +70, Gunnery/'Mech +15, Piloting/BattleMech +15, and the six-component Clan MechWarrior Field at +80 XP per Skill for a governed 384 XP Field purchase. The included Field records zero additional chronology because its training is part of the 16-year Sibko module. A 50 XP flexible pool remains pending for explicit later allocation.

Source: *A Time of War—The BattleTech RPG*, Corrected Third Printing, p. 79 (Sibko) and p. 95 (Clan MechWarrior Field). The implementation is internal only and does not activate Clan UI or readiness.
