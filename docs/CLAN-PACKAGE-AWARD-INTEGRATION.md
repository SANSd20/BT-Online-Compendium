# Clan Package Award Integration — Alpha Slice 141

Slice 141 adds internal transactional award support for the source-backed Clan
affiliation packages from *A Time of War*, Corrected Third Printing, pp. 69–71.

Invading Clan costs 75 XP and grants Compulsion/Arrogance –50,
Compulsion/Distrust of Inner Sphere –100, Interest/Clan Remembrance +25, and
Protocol/Clan +25. Homeworld Clan costs 50 XP and grants Compulsion/Distrust
of Inner Sphere –100, Compulsion/Hate Invading Clans –100,
Interest/Clan Remembrance +25, and Protocol/Clan +25.

The MechWarrior caste package has internal fixed Attribute/Trait award support
for its p. 71 values. Other caste/sub-caste packages remain governed metadata
or deferred where source-defined concrete Skill/Trait choices are not yet
supported. Invalid or unsupported package bundles reject atomically.

Package records retain canonical identity, source provenance, XP accounting,
and durable history. Clan creation and Clan readiness remain unavailable in the
Public Alpha.
