# Alpha Slice 165-B7 — Initial atomic Homeworld Clan transactions

Blood Spirit and Ice Hellion are the first internally executable specific-Clan packages. Each requires the canonical Clan affiliation and a committed generic Homeworld Clan package, has no separate acquisition cost or chronology duration, applies every fixed catalog award with signed values, and records one B5 committed-history transaction. A second specific-Clan commitment is rejected atomically.

The bounded transaction operation is internal only. It does not activate Clan selection, Clan readiness, or public Clan import. The other six Homeworld Clan packages remain inactive because their governed or conditional dependencies are not complete for this transaction scope. No unsupported destination is substituted.

The transaction uses Build → Validate → Commit. Failed operations preserve the base character, XP, chronology, and provenance. The committed history records the canonical Clan, package, transaction, award identities, signed amounts, choices, and source provenance. Generic Homeworld benefits remain separate and are not reapplied.
