# Alpha Slice 165-B2 — conditional eligibility and Trait legality foundation

This slice adds structured internal eligibility evaluation for the eight Homeworld Clan identities. The evaluator distinguishes `ELIGIBLE`, `INELIGIBLE`, and `UNRESOLVED_REQUIRED_CHOICE`, preserves source provenance, checks Clan affiliation and Clan-only Phenotypes, validates the B1 governed draft, and rejects modeled opposing Trait choices.

No specific-Clan awards are applied. The evaluator does not invent service-era values or treat missing chronology context as satisfied. Public Clan import, player-facing selection, Clan readiness, and full atomic award transactions remain disabled.

Phenotype, caste, language, and service-era rules remain explicit dependencies where the current character state cannot safely establish a source-complete condition. Slice 165-B3 remains responsible for completing canonical destination and transaction integration after these eligibility results are consumed.
